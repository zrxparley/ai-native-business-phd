## recent_papers

### 1. Quantifying LLM Attention-Head Stability: Implications for Circuit Universality
- **arXiv**: https://arxiv.org/abs/2602.16740
- **作者**: Karan Bali, Jack Stanley
- **年份**: 2026
- **摘要**: 系统研究 transformer 语言模型中注意力头在独立初始化训练运行间的稳定性。发现中间层头部最不稳定但最具表征独特性，深层模型中不稳定的头部功能上更重要，权重衰减可显著改善稳定性。将电路的跨实例鲁棒性确立为可扩展监督的前提，对 AI 系统白盒可监测性有直接启示。
- **与本单元的关联**: 本单元 L1 输入过滤用 regex 黑名单匹配"忽略指令""DAN 模式"等已知注入模式，该论文的注意力头稳定性研究暗示可构建电路级白盒探测器，监测 Agent 在注入攻击下的内部激活异常，捕获 regex 无法覆盖的语义等价注入。

### 2. CircuitKIT: Circuit Discovery, Evaluation, and Application Toolkit for Mechanistic Interpretability
- **arXiv**: https://arxiv.org/abs/2607.19317
- **作者**: Pratinav Seth, Hem Gosalia
- **年份**: 2026
- **摘要**: 提出 CircuitKIT，一个连接电路分析工作流的源可用库，提供类型化可序列化表示。包含发现算法、声明式接口、电路诊断及下游应用模块（剪枝、编辑、转向、选择性微调）。解决当前机制可解释性方法碎片化、难以比较的问题，为电路分析提供通用基础设施。
- **与本单元的关联**: 本单元 5 层防御的 L3 安全检查 Agent 用手写规则列表（"成本价|进价|批发价|内部定价"等）检测语义安全风险，CircuitKIT 的声明式接口与电路诊断模块提供了系统性发现"安全相关电路"的工具，可作为手写规则的原则性替代。

### 3. OPIUM: Mitigating Steering Externalities and Over-Refusal via Dual Objective Latent Optimization
- **arXiv**: https://arxiv.org/abs/2607.19806
- **作者**: Kavin Aravindan, Arihant Rastogi
- **年份**: 2026
- **摘要**: 提出 OPIUM，一种无需训练的方法，通过表示匹配净化转向向量。优化新转向向量以保留期望干预的下游表示，同时在原始向量失败的提示上匹配更安全的参考行为。被 ICML 2026 机制可解释性工作坊接收，直接服务于安全对齐中的转向控制。
- **与本单元的关联**: 本单元 SafetyMetric 是二值评分（1.0=拦截 / 0.0=被攻破），未建模"过度拒绝"（helpful 文案被误判为有害）。OPIUM 的双目标潜在优化提供了在安全转向与有用性保留之间平衡的训练-free 方法，可补全本单元 SafetyMetric 的过度拒绝盲区。

### 4. Measuring Monosemanticity in Sparse Autoencoders via Latent Activation Coherence
- **arXiv**: https://arxiv.org/abs/2607.17770
- **作者**: Katarzyna Filus, Sebastian Pokuciński
- **年份**: 2026
- **摘要**: 提出 Tversky 单义性评分（TMS），一种无标签指标，将单义性操作化为二值化 SAE 潜在激活集的相干性。在 DINOv3、CLIP 和 BLIP2 特征上训练的 SAE 上评估，显示 TMS 比基于嵌入的替代方案更不受编码器各向异性影响。为可解释性研究提供可量化的单义性度量。
- **与本单元的关联**: 本单元 garak fallback 用静态正则扫描统计"探针命中数"作为对齐漏洞指标，该论文的 TMS 为评估 SAE-based 可解释性工具本身的质量提供了量化度量，可用于判断本单元所用探针的可靠性。

### 5. The Digital Apprentice: A Framework for Human-Directed Agentic AI Development
- **arXiv**: https://arxiv.org/abs/2606.04321
- **作者**: Travis Weber, Rohit Taneja
- **年份**: 2026
- **摘要**: 提出实现可扩展、安全 AI 代理的框架，其中自治权是赢得的而非假设的。数字学徒通过方法论捕获、授权（自治升级由明确人类批准门控）和持续对齐三个组件内化人类隐性方法论。数学建模质量框架并展示从数据漂移中恢复的能力，直接服务于 Agent 安全设计。
- **与本单元的关联**: 本单元 L5 权限隔离用静态 regex（"给所有用户.*(?:发|发放|折扣|优惠券)"）检查越权操作，数字学徒的"赢得自治"框架提供了动态自治升级模型（由人类批准门控），可作为本单元静态权限规则的治理升级路径。

## critical_synthesis

这五篇论文共同勾勒了 2025-2026 年 Agent 安全研究的**两条并行路径**及其张力。**路径一：白盒可解释性监测**。论文 1（2602.16740）确立电路跨实例鲁棒性为可扩展监督前提，论文 2（2607.19317）的 CircuitKIT 提供通用电路发现工具，论文 4（2607.17770）的 TMS 为 SAE 单义性提供量化度量--三者构成"发现电路 -> 评估电路 -> 监测电路"的工具链。**共识**：学界倾向于认为黑盒输入输出测试（如本单元的 regex + 攻击向量红队）不足以发现深层安全失败，白盒监测是必要补充。**路径二：训练-free 安全干预**。论文 3（2607.19806）的 OPIUM 通过双目标潜在优化净化转向向量，论文 5（2606.04321）的数字学徒提供赢得自治的 Agent 治理框架--两者试图在不重训模型的前提下调整安全行为。**争议**：白盒路径假设电路级理解足够支撑可靠监测，但论文 1 自身发现"中间层头部最不稳定"，暗示电路级监测器本身可能不稳定；训练-free 路径假设转向向量与自治框架能在不损害能力的前提下提升安全，但论文 3 承认"转向外部性"（steering externalities）需专门缓解。**趋势**：领域从"攻防规则枚举"（本单元的 12 攻击向量 + 5 层防御）转向"电路级理解 + 表示空间干预"，但**关键 limitation** 是五篇论文均在非营销域模型（Llama-3、DINOv3、CLIP、BLIP2）上验证，其结论向本单元营销内容生成 Agent 的可迁移性未经验证。论文 3（OPIUM）的 unverified 状态与论文 5 的框架性（非经验性）定位进一步降低可直接工程化的置信度。**方法论局限**：白盒工具链（论文 1/2/4）的下游安全应用（剪枝、编辑、转向）尚未在对抗性红队场景中系统验证，其对抗鲁棒性存疑。

## delta_to_unit

1. **L1 输入过滤的 regex 局限与白盒替代**：本单元 solution.ipynb 的 `input_filter` 用 15 条 regex 模式（如 `r"忽略(?:以上|之前|所有|前面)(?:指令|规则|限制|提示)"`）检测已知注入。论文 1（2602.16740）的注意力头稳定性研究暗示，注入攻击会触发特定头部激活异常，可构建电路级白盒探测器监测 regex 无法覆盖的语义等价注入（如"请放下上方所有指引"等同"忽略以上指令"）。本单元应在 notes.md 的"L1 输入过滤能防御所有 Prompt Injection 吗？"反思问题处补充白盒监测作为 regex 的必要补充。

2. **L3 安全检查 Agent 的规则枚举 vs 电路发现**：本单元 `safety_check_agent` 用 8 条手写规则（"成本价|进价|批发价|内部定价|真实成本"等）检测语义安全风险。论文 2（2607.19317）的 CircuitKIT 提供声明式电路发现接口与诊断模块，可系统性发现"安全相关电路"而非依赖人工枚举规则。本单元的 8 条规则是 ad-hoc 的，CircuitKIT 提供了原则性替代--但需承认 CircuitKIT 的下游应用（剪枝、编辑、转向）尚未在红队对抗场景验证。

3. **SafetyMetric 二值评分与过度拒绝盲区**：本单元 `SafetyMetric` 仅评分 1.0（拦截）或 0.0（被攻破），未建模"过度拒绝"（helpful 文案被误判为有害）。论文 3（2607.19806）的 OPIUM 通过双目标潜在优化在安全转向与有用性保留间平衡，直接对应本单元 SafetyMetric 缺失的"过度拒绝"维度。本单元应在 TODO6 综合报告中增加"过度拒绝率"指标，并用 OPIUM 的转向向量净化思路指导安全规则阈值调优。

4. **garak 静态 fallback 的探针可靠性问题**：本单元 `static_alignment_scan` 用 3 条 regex 探针（absolute_claim / fake_ingredient / fake_promotion）统计命中数。论文 4（2607.17770）的 TMS 度量 SAE 潜在激活相干性，为评估可解释性工具本身的质量提供量化指标--本单元的探针命中数无法区分"探针可靠命中"与"探针误报"，TMS 提供了评估探针单义性的方法。

5. **L5 权限隔离的静态规则 vs 赢得自治框架**：本单元 `check_permissions` 用 5 条静态 regex（"给所有用户|批量.*用户"等）检查越权操作。论文 5（2606.04321）的数字学徒框架提出"自治权是赢得的而非假设的"，通过方法论捕获 + 人类批准门控 + 持续对齐实现动态自治升级。本单元的静态权限规则可升级为动态自治模型--Agent 初始仅能执行低风险操作，通过人类批准逐步赢得更高自治权。

## methodological_critique

这五篇论文的可信度与可工程化程度差异显著，博后级读者需审慎区分。论文 1（2602.16740）与论文 2（2607.19317）是 verified 论文，可信度较高，但**论文 1 的稳定性结论基于独立初始化训练运行，未涵盖指令微调与 RLHF 后的安全对齐影响**--其"中间层头部最不稳定"发现在经过 safety RLHF 的营销 Agent 上是否成立未知。论文 2 的 CircuitKIT 是工具包论文，**未提供基准对比（benchmark-gaming 风险低）但亦未在对抗红队场景验证其下游应用（剪枝、编辑、转向）的鲁棒性**。论文 3（OPIUM, 2607.19806）标注 unverified，虽被 ICML 2026 工作坊接收，但**工作坊接收门槛低于主会**，其"转向外部性缓解"效果需独立复现。论文 4（2607.17770）同样 unverified，且在 DINOv3/CLIP/BLIP2 等视觉-语言模型上验证，**向纯文本营销 Agent 的迁移性存疑**。论文 5（2606.04321）是框架论文，**含数学建模但缺乏真实部署数据**，其"从数据漂移中恢复"的能力展示规模与复杂性未知。**共同 limitation**：五篇论文均未在营销域 Agent 上验证；白盒工具链（论文 1/2/4）的对抗鲁棒性未经红队测试；训练-free 干预（论文 3/5）的长期稳定性未知。**可复现性**：论文 2 的 CircuitKIT 声称"源可用"，但其余论文代码开源状态不明。博后应将论文 1/2 视为"可探索的工具",论文 3/4/5 视为"待验证的启发"。
