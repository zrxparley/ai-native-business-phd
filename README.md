## 项目简介

这是一个**非传统意义上的博士课程**——它不颁发学位，但要求你达到博士级的思维深度与工程能力。

**核心理念**：

| 理念 | 说明 |
|------|------|
| 🎯 表示即知识 | 让AI"读懂"企业，从数据表示开始 |
| 📊 规模揭示本质 | 大规模实验与落地，不做纸上谈兵 |
| 🎯 目标即终点 | 战略定义与量化目标闭环 |
| 🔧 做出来才算数 | 应用工程倾向，每个技能都有可交付产出 |

**设计背景**：结合宿主的五大背景维度（AI+企业营销 / AI原生化转型 / 战略规划与落地 / 跨学科商业模式 / 应用工程倾向），由**系统觉醒（system-awakening）** 天赋技能树系统生成，经**天道推演系统**八维验证，融合**AI+Business Analytics硕士**学位课表结构。

| 编号 | 技能 | 级别 · 时长 | 解锁条件 | 核心命题 |

| 5 | **Agentic系统工程与落地** | 大师 · 14h | 完成技能4 | 怎么把上面四个技能做出来？ |

## 英语平行轨道

> 基于 **Oxford Natural Approach**（Krashen & Terrell），不背单词、不学语法、不考试——用真实学术内容自然习得。

### 五大核心假说

| 假说 | 应用在博士课程中 |
|------|-------------------|
| **习得 > 学习** | 读懂CMU讲义 → 自然掌握学术英语，不背单词表 |
| **i+1 可理解输入** | 每个技能配"刚好超出当前水平一点"的英文材料 |
| **自然顺序** | 不按语法书顺序，按技能认知顺序学英语 |
| **监控假说** | 不纠错、不中断表达，先流利再准确 |
| **情感过滤** | 零焦虑：不考试、不排名、不批评发音 |

### 轨道结构（嵌入每个技能，不单独占用时间）

## 适合人群

这套课程最适合以下背景的学习者：

- ✅ **AI+行业应用从业者**：想把AI真正用在企业营销/运营/战略中
- ✅ **跨学科背景**：技术+商业/营销/战略，不想只做纯技术或纯商业
- ✅ **应用工程倾向**：相信"做出来才算数"，不喜欢纯理论空转
- ✅ **博士级自我要求**：愿意投入100+小时，接受作业和费曼输出训练
- ✅ **英语进阶需求**：需要用英文读论文/白皮书，但不想走传统英语学习方法

## 天道推演框架

v2.0 引入的**八维推演分析**，确保每个技能模块经得起压力测试：

| 维度 | 推演问题 |
|------|----------|
| 🔗 **因果链** | 学了这个技能，能直接导致什么结果？ |
| 🎯 **博弈方** | 谁会因为这个技能受益/受损？ |
| 📊 **变量** | 哪些变量会放大/削弱这个技能的效果？ |
| 🔀 **分支点** | 学的过程中哪些决策点会决定最终效果？ |
| 🎲 **概率** | 认真学完，实际能用上的概率有多少？ |
| ⏳ **时间线** | 这个技能的效果，多久能显现？ |
| 🦋 **蝴蝶效应** | 这个技能中哪个小细节，可能产生超比例影响？ |
| 🏁 **终局** | 学完所有技能，终局状态是什么？ |

> 完整推演分析见 v2.0/v3.0/v3.1 主教材卷首。
