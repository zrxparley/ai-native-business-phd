## Overview

Not a degree-granting program - but it demands doctoral-grade depth and engineering rigor. A self-study system generated by the **system-awakening (系统觉醒)** talent-tree framework, validated by the **Tian Dao Tui Yan (天道推演)** sandbox-deduction system across eight dimensions, and aligned to an **AI + Business Analytics** master's curriculum.

| Principle | Meaning |
|---|---|
| 🎯 Representation is knowledge | Make AI "read" the enterprise - start from data representation |
| 📊 Scale reveals essence | Large-scale experiments & deployment, no paper-only theory |
| 🎯 Goal is the destination | Strategy definition + quantified targets form a closed loop |
| 🔧 Ship it or it doesn't count | Applied-engineering bias - every skill ships a deliverable |

## Tian Dao Tui Yan

The **Tian Dao Tui Yan (天道推演)** framework - a meta-cognitive sandbox-deduction capability that builds branching future scenarios in consciousness and picks the optimal path - stress-tests every skill module across eight dimensions (introduced v2.0):

| Dim | Question |
|---|---|
| 🔗 Causal chain | What does learning this skill directly cause? |
| 🎯 Players | Who gains / loses from this skill? |
| 📊 Variables | What amplifies / dampens its effect? |
| 🔀 Branch points | Which mid-learning decisions determine the outcome? |
| 🎲 Probability | If studied seriously, how likely is it to pay off? |
| ⏳ Timeline | How long until effects show? |
| 🦋 Butterfly | Which small detail has outsized impact? |
| 🏁 Endgame | After all skills, what's the terminal state? |

Full deduction analysis in the v2.0 / v3.0 / v3.1 textbook front matter.
